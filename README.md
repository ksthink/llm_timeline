# LLM TIMELINE

2015–2026 AI 모델 283건을 한 장의 동적 타임라인으로 봅니다. 차트는 [Apache ECharts](https://echarts.apache.org/)입니다. 시간 축, 라인, 스캐터, `dataZoom`을 한 차트에서 씁니다.

파도는 시간의 줄기입니다. 위쪽 점은 오픈웨이트·오픈·오픈(코드), 아래쪽 점은 비공개, 파도 근처의 점은 미확인입니다. 세로 위치는 성능 점수가 아닙니다. 선 색은 다섯 시대(기반, 사전학습, 생성, 경쟁, 추론)입니다.

전체 기간에서는 이정표 17개만 `YYMM` 숫자로 보입니다. 휠이나 슬라이더로 좁히면 이름이 나타나고, 점을 누르면 오른쪽에 설명과 출처가 열립니다. 흰 테두리는 한국 모델, 빈 점은 검증 상태가 수정, 다이아몬드는 불일치·확인불가입니다.

## 실행

```bash
npm install
npm test
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

## 데이터

원본은 `data/models.csv` 입니다. 고친 뒤 아래를 실행하면 `src/data/models.json` 이 다시 만들어집니다.

```bash
npm run data
```
